# Focused paper review

1. Combine confirmation and sequential reading under an explicit start action, with retry and manual-review fallback.
2. Classify only unambiguous objective answers for automatic scoring; flag missing, blank, unclear, conflicting, and uncertain marks. Require teacher review for essays and identity.
3. Show flagged items by default and allow inspection and correction of all answers. Atomically recompute automatic decisions and verify completeness during finalization.
4. Show an accessible success dialog after confirmed finalization. Test classification, run checks, and preserve existing data.
